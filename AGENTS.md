# Trabajo en este repositorio

- Mantener `README.md` actualizado con cada cambio: comportamiento real, instalación, comandos y limitaciones pertinentes.
- Consultar `docs/PLAN.md` antes de continuar una implementación y actualizar el estado de las etapas cuando corresponda.
- Validar los cambios antes de hacer commit. Documentar las comprobaciones y cualquier limitación pendiente.
- No versionar credenciales, archivos de entorno locales ni logs.
- Hacer push cuando el usuario lo solicite o lo haya autorizado para la tarea en curso.
